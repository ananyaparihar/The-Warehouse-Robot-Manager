The Warehouse Robot Manager

An algorithmic backend for an autonomous e-commerce warehouse robot fleet — indexing a large SKU catalogue for fast lookup, routing robots across the warehouse floor, packing each robot's payload within capacity, coordinating multi-stop pick routes, and dispatching pending tasks in real time as new orders arrive.
